# Treeye header artwork

`icon.svg` and `wordmark.svg` are copied **verbatim**, byte for byte, from the
built `<header class="site-header">` of the Treeye site (#172):

- repository: `ruipinge/treeye`
- file: `public/index.html` (the home link's two `<svg>` elements)
- commit: `bb1cf93`
- generated by `brand/build_site.py` (`header_icon`, `header_word`), sized by
  the `.site-header .home` rules in `brand/base.css`

Do not edit them by hand. To check for drift, diff each file against the
matching line of `public/index.html` at the site's current commit, with the
leading indentation stripped. If the site's artwork changes, copy it again and
update the commit above.
